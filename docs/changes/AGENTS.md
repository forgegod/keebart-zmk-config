# Change records

## Purpose

Progress records for material config changes.

## Ownership

`README.md`, `active/`, `archive/`, and optional `reviews/CHG-<number>/` packages.

## Local Contracts

One active CHG owns each material request. Planned phases stay pending until a phase is explicitly reserved. The unicode pin CHG does not edit keymap bindings.

## Work Guidance

Read `README.md` before adding a record. Do not start a phase from a planning write. The firmware workflow, not the record script, proves a pin change builds.

## Verification

Run `node scripts/check-product-records.mjs` and the phase gate named in the CHG.

## Child DOX Index

None.
